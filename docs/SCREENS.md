# 화면 명세

## 구성 (한 페이지)

1. **헤더**: 제목, 백엔드 연결 상태 점(초록: 정상 / 노랑: 지연 / 빨강: 끊김), "CVE 재생" 입력 + 버튼
2. **요약 카드 3개**: 긴급 / 높음 / 보통 건수 (`GET /impacts`의 `priority.tier` 집계)
3. **영향 카드 목록** (왼쪽, 우선순위 순)
   - 항목: 서비스명, 패키지, 설치 버전 → 패치 버전, 상태 배지, 티어 배지
   - 선택하면 오른쪽 상세 패널이 열린다
4. **상세 패널** (오른쪽)
   - 근거(`priority.reasons`) 목록
   - 수정 내용: `remediation.text`, `remediation.kind`
   - diff: `remediation.diff`가 있으면 줄 단위로 색을 입혀 표시 (추가 초록, 삭제 빨강)
   - 재스캔: `rescan` 값 (`0`이면 "재스캔 0건" 강조)
5. **위협 카드 목록** (아래): `GET /cards`. 열 항목은 키, 상태(확정/미확정), KEV, EPSS, 버전
6. **카드 상세**: 행을 누르면 `GET /cards/{key}`로 요약·출처·영향받는 범위를 보여준다.

## 상태별 동작

| 상태 | 표시 |
|---|---|
| 최초 로딩 | 스켈레톤 또는 "불러오는 중" |
| 목록 비어 있음 | "아직 영향 카드가 없습니다. 'CVE 재생'으로 샘플을 넣어 보세요." |
| 백엔드 다운 | 헤더 빨간 점 + 마지막 갱신 시각. 목록은 마지막 성공 값을 유지 |
| 재생 요청 실패 (404) | "KEV에 없는 CVE입니다" |
| 재생 요청 성공 (202) | "처리 중" 표시 후 3초 뒤 목록 갱신 |

## 갱신 주기

- `GET /impacts`, `GET /cards`: 3초마다 (`src/config.js`의 `REFRESH_MS`)
- 탭이 백그라운드이면 갱신을 멈춘다 (`document.hidden`)

## fixture 모드

- `src/config.js`의 `USE_FIXTURE = true`이면 `tests/fixtures/impacts.json`, `cards.json`을 읽는다.
- 백엔드가 없을 때 화면을 확인하는 용도다. 배포 설정에서는 `false`.

## 접근성·표기

- 색만으로 상태를 구분하지 않는다. 배지에 글자를 함께 쓴다(긴급, 높음, 보통).
- 숫자는 천 단위 구분 없이 그대로 쓴다. 날짜는 `YYYY-MM-DD`.
- 한국어 UI. 식별자(CVE, GHSA, 패키지명)는 원문 그대로.
